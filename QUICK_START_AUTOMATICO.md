# Quick Start Automatico — Algohns V9.2

1. Doppio click su `0_START_HERE_INSTALL_KEYS_DEPLOY.bat`.
2. Lo script installa le dipendenze, configura Wrangler locale, salva/riusa le chiavi eToro e fa deploy.
3. Apri il link Cloudflare mostrato alla fine.

Le viste principali aggiornate sono `Portfolio → Combined / Alpaca / eToro` e `Orders → All / Alpaca / eToro`.
