# eToro keys

Le chiavi vengono salvate localmente in:

```text
%USERPROFILE%\.algohns
```

File usati:

```text
ETORO_API_KEY.txt
ETORO_USER_KEY.txt
ETORO_BASE_URL.txt opzionale
```

Per aggiornare solo le chiavi usa:

```text
4_SET_ETORO_KEYS_ONLY.bat
```

Per riusare le chiavi già salvate e deployare usa:

```text
5_REUSE_SAVED_ETORO_KEYS_AND_DEPLOY.bat
```
